How to switch

# In .env
LLM_PROVIDER=anthropic
LLM_MODEL=claude-haiku-4-5-20251001
ANTHROPIC_API_KEY=sk-ant-...

Then restart the app. The selected provider drives both Strategy B query expansion and chatbot generation. If the provider fails, the system falls back gracefully to a context-based response.

Vector store

BackendFAISS — IndexFlatIP (exact cosine via inner product on L2-normalized vectors)
PersistenceFile-backed (faiss.index + JSON metadata)
Path{{ cfg.vector_store_path }}

PDF explicitly allows: "FAISS, ChromaDB, or a simple NumPy implementation". FAISS is chosen for industry-standard performance, prebuilt wheels, and easy upgrade path to approximate indexes (IndexHNSWFlat, IndexIVFFlat) at scale. Swappable via the IVectorStore interface — see docs/ARCHITECTURE.md for the Vertex AI Matching Engine migration path.
